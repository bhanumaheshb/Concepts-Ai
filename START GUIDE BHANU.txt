--------------------------------------------------------------------------------
  IF SOMETHING DOES NOT START
--------------------------------------------------------------------------------

"npm is not recognized"
    Your terminal is older than the PATH change. Open a NEW terminal, or use:
    "C:\Users\Bhanu Mahesh Bathula\AppData\Local\Programs\nodejs\npm.cmd" --prefix C:\dev\concepts-ai\frontend run dev

"Port already in use"
    Something is still holding 8001 or 3000. In PowerShell:
    Get-NetTCPConnection -LocalPort 8001 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }

"Failed to fetch" in the browser
    Backend is not running, or is on the wrong port.
    Check:  curl http://localhost:8001/api/health

OSError [Errno 22] / "Permission denied" reading a project file
    This means the files are being read from a OneDrive-synced folder.
    ALWAYS work in C:\dev\concepts-ai - never the old OneDrive copy.

To change how many concepts are generated, edit DEFAULT_K in backend\.env
AND the fallback in frontend\lib\api.ts (search for: input.k ?? 10).

To switch the creative cognition layer OFF, comment out
CREATIVE_COGNITION_ENABLED and restart the backend. The pipeline then behaves
exactly as it did before that layer existed.


--------------------------------------------------------------------------------
  HOW THE ENGINE UNDERSTANDS A BRIEF   (Design Intelligence)
--------------------------------------------------------------------------------

The engine now reads WHAT the brief is before designing anything. The form
pre-selects nothing: leave "Type of space" and "What is the event" empty and the
brief is read as written. You can type ANY event name - "Poetry night",
"Astronomy storytelling night" - it does not need to be in a list.

While you type, the form shows "Understood as": the event, what it is organised
around, the zones it needs, and what it will NOT contain (a Sangeet: no mandap,
no ritual fire, no priest platform).

Adding a new event type or ritual element is DATA, not code:

    backend\app\semantics\knowledge\v1\events.yaml       event types + families
    backend\app\semantics\knowledge\v1\activities.yaml   activity -> zones
    backend\app\semantics\knowledge\v1\elements.yaml     elements + where they belong

An event not in events.yaml still works: its programme is inferred from the
activities the brief mentions (projection, narration, dining, runway...).


--------------------------------------------------------------------------------
  WHAT TO EXPECT WHEN YOU PRESS "GENERATE CONCEPTS"
--------------------------------------------------------------------------------

The deterministic engine finishes in well under a second. Then it waits on
LM Studio, which takes roughly 2.5 minutes PER CONCEPT on a local model.
At k=10 that is around 25 MINUTES for a full run. Lower DEFAULT_K while you
are iterating.

In the backend terminal you will see the stage trace:

    01   Design intelligence    Sangeet [sangeet] via merged: 12 zones, 15 forbidden
         SEMANTIC INTERPRETATION block: event, activities, PROGRAMME, forbidden
    04   Search space           ... (5 out of semantic scope), 5 semantic priors
    08   Phenotype synthesis    16 phenotypes
    08c  Creative cognition     +8 concepts from 8 operations
    09   Critics                24/24 passed all four gates
    09c  Creative evolution     +0 evolved from critic findings
    11   Diversity evaluation   vendi=... min=...
    12   Portfolio selection    10 selected, curriculum satisfied
    14b  Creative synthesis     LM Studio writes each concept
    14c  Visual direction       what each image must show, then the prompts
